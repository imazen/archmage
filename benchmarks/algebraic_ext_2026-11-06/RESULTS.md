# Focused workload results

All times are ns/input value for 1,024 values. Dot returns one reduction result.
Intervals are 95% paired mean-difference bootstrap intervals using all retained
rounds, 10,000 resamples, seed 20261106. No post-hoc round exclusion here; this is
separate from zenbench's own baseline analysis. Mean/median gaps and drift
remain visible in CSVs and raw JSON. Close point estimates are not rankings.

WASM setup allocates cases/inputs/output per host call, amortized over 256 repeats;
native setup is outside iteration. Do not treat absolute cross-platform values
as identical wrapper workloads. LTO modes are separate measured binaries.
